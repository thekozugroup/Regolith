# UI polish audit — 2026-10-03

Scope: existing Regolith UI, not printer behavior. Baseline `91b5fe7`.

Method: [Impeccable](https://impeccable.style) audit/frontend-design/polish guidance and [Taste's existing-project redesign audit](https://github.com/Leonxlnx/taste-skill/blob/main/skills/redesign-skill/SKILL.md), followed by targeted implementation and browser verification. Read-only independent review used Sol; bounded picker work used Terra; feedback semantics used Luna. Existing owner decisions override generic style advice: Inter, neutral surfaces, segmented instruments, semantic color, aligned grid, derived radii, no decorative glow or Liquid Glass.

## Findings and changes

| Priority | Evidence in baseline | Change |
| --- | --- | --- |
| High | Brand picker had no initial keyboard focus, inconsistent focus return, and no viewport-height bound. | Non-modal focus lifecycle, explicit ARIA relationship, measured viewport bounds, scrollable content, resize dismissal, preserved image upload. |
| Medium | Camera actions hid at `sm` regardless of input capability. Larger touchscreens have no hover to reveal them. | Hide only for fine-pointer devices with hover; keep touch actions visible and at least 44px. |
| Medium | Bed marker interpolated `left/top`; memory and render bars interpolated `width`. | Translate the position layer and scale full-width bars. Existing reduced-motion policy still applies. No new animation library or device polling. |
| Medium | Timelapse's entire activity block was a live region, including changing frame counts and percentages. | Announce phase changes through a stable live region; expose progress separately as a named progressbar. |
| Low | Profile import and preference backup feedback lacked announcements. | Stable status/error regions, visually absent when empty. No changes to import/export/reset behavior. |
